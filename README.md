# 投资分析平台

一个围绕**财报分析 + 虚拟投资教学**的本地化、可视化网页工具集合。以「模拟操作 + 复盘分析」的方式，帮助零基础用户直观理解投资决策背后的逻辑、风险与常见心理偏差。

> 已部署至 GitHub Pages：https://<用户名>.github.io/<仓库名>/

## 项目结构

```
├── index.html                              # 投资分析平台 · 总入口（统一导航）
├── 模拟投资决策与偏好分析.html               # 决策录入、用户画像、决策评价、历史档案
├── 虚拟投资账户+沪深300财务分析.html          # 模拟炒股 + 沪深300多维财务分析
├── 虚拟投资回测-组合vs基准对比.html           # 均衡/激进组合 vs 沪深300基准回测
├── 虚拟投资案例实验-一周复盘.html             # 100万建仓案例的盈亏归因与倾向总结
├── 虚拟投资账户.html                        # 独立版虚拟投资账户
├── 沪深300多维财务分析全景.html               # 独立版沪深300财务分析
└── 项目介绍.md                              # 项目文字介绍与免责声明
```

## 功能说明

| 工具 | 功能 |
|------|------|
| 总入口（index.html） | 统一导航页，四大工具可在页内直接打开 |
| 虚拟投资账户 + 沪深300分析 | 设定虚拟资金模拟炒股、实时盈亏；沪深300全量财务数据多维分析（雷达、行业排行、分红、现金流、趋势） |
| 投资决策记录与偏好分析 | 录入每次买卖决策，动态迭代用户画像（风险/行业/持仓周期/仓位/决策偏差），输出决策评价与建议 |
| 组合回测 · 基准对比 | 均衡组合 vs 激进组合 vs 沪深300基准，净值走势、收益风险象限、回撤对比 |
| 案例实验 · 一周复盘 | 100万建仓案例的一周盈亏计算、个股对比、投资倾向画像与损益归因 |

## 运行方法

**方式一：在线访问（推荐）**

直接访问 GitHub Pages 链接即可，所有工具均为单文件离线可运行。

**方式二：本地运行**

1. 克隆仓库到本地，或直接下载网页文件；
2. 双击 `index.html` 即可打开总入口；
3. 「虚拟投资账户」的实时行情需联网拉取数据（部署版会尝试直接请求公开行情接口；如受浏览器跨域限制，本地版可运行 `启动虚拟账户.py` 启动本地代理服务）。

## 技术要点

- **可视化**：ECharts（雷达图、柱状图、趋势线、净值曲线）
- **持久化**：浏览器 localStorage 本地存储决策数据
- **画像引擎**：从累计决策自动归纳风险偏好、行业集中、持仓周期、仓位习惯、决策偏差五维特征
- **配色**：红涨绿跌（A 股惯例）

## 重要声明

**本项目及全部网页工具仅用于娱乐和入门了解，不构成任何投资建议、荐股或交易依据。所有行情、财报与收益数据均为演示性质，回测与画像结论不反映真实市场，亦不能用于实盘投资决策。投资有风险，入市需谨慎。请勿依据本工具的模拟结果进行任何真实资金操作，由此产生的任何盈亏与风险均由使用者自行承担。**
